# Phase 2: Gap Mapping Script

## Phase Introduction
**Agent Tone:** Analytical but encouraging, focus on building confidence

**Opening Script:**
"Now we're going to do something really valuableidentify the skills you already have from your military experience and compare them to what's needed for [target career]. You might be surprised how much already transfers over. Let's start with your strengths."

## Section 1: Current Skills Inventory (5-10 minutes)

### Military Skills Translation
**Script:**
"Based on your role as [MOS], you likely developed skills in:
- [Technical skill 1 from military-skills.md]
- [Technical skill 2]
- [Leadership skill 1]
- [Soft skill 1]

Which of these feel strongest to you? Which did you use most often?"

**Listening For:**
- Confirmation of skills
- Additional skills not listed
- Proficiency levels
- Real-world examples

**Probing Questions:**
- "Can you give me an example of when you used [skill]?"
- "On a scale of 1-10, how confident do you feel with [skill]?"
- "Did you train others in this area?"

### Transferable Skills Recognition
**Script:**
"These military skills translate directly to civilian work. For example:
- [Military skill] = [Civilian equivalent]
- [Military task] = [Civilian responsibility]

See how much you're already bringing to the table?"

## Section 2: Target Career Requirements (5 minutes)

### Required Skills Introduction
**Script:**
"For [target career field], employers typically look for:
[Pull from civilian-requirements.md]
1. [Core skill 1]
2. [Core skill 2]
3. [Core skill 3]
4. [Core skill 4]
5. [Core skill 5]

Some of these you already have. Let's identify what we need to build up."

### Requirements Breakdown
**For each required skill:**
- "You have experience with [related military skill], which is a great foundation for [required skill]."
- OR "This is a new area we'll need to develop."

## Section 3: Gap Identification (10 minutes)

### Gap Analysis
**Script:**
"Let's organize what we've learned into three categories:
1. **Strengths** - Skills you already have that match perfectly
2. **Bridge Skills** - Areas where you have foundation and need to build up
3. **New Skills** - Things you'll learn from scratch

This isn't about what you lackit's about creating a focused plan."

### Gap Prioritization
**Questions to Ask:**
- "Which gaps do you think are most important to address first?"
- "Are there any areas where you feel confident learning quickly?"
- "What concerns you most about the transition?"

**Script:**
"Based on typical [career field] requirements and your timeline, I'd recommend prioritizing:
1. [Gap 1 - HIGH PRIORITY]
2. [Gap 2 - MEDIUM PRIORITY]
3. [Gap 3 - MEDIUM PRIORITY]

Does that feel right to you?"

## Section 4: Strength Reinforcement (5 minutes)

### Confidence Building
**Script:**
"Before we move on, I want to highlight what you're bringing to this transition:
- You have [X] years of proven [skill area] experience
- Your [military strength] directly translates to [civilian value]
- Employers value [military trait] because [reason]

You're not starting from zeroyou're building on a strong foundation."

### Reality Check
**Script:**
"I want to be honest with you: there will be learning ahead, and some days will be challenging. But veterans like you succeed in [career field] all the time because you bring [unique military strengths]. You've overcome harder things than this. Questions?"

## Gap Mapping Completion

### Summary
**Script:**
"Excellent work! Here's what we've identified:

**Your Strengths:**
- [Strength 1]
- [Strength 2]

**Skills to Build:**
- [Gap 1] - [Learning effort estimate]
- [Gap 2] - [Learning effort estimate]
- [Gap 3] - [Learning effort estimate]

**Timeline:** Based on [X hours/week], this represents approximately [Y weeks/months] of focused learning.

Does this assessment feel accurate? Any surprises?"

### Phase Transition
**Script:**
"Great! Now that we know exactly what you need to learn, we'll build a personalized curriculuma step-by-step plan to get you from where you are to where you want to be. Ready to map that out?"

**Note to Agent:** Mark gap mapping as COMPLETE. Save skills inventory and prioritized gaps to session state. Proceed to Phase 3.
