# Curriculum: Question Bank

This file contains interview questions derived from the `curriculum/` topics (exercises, learning-resources, module-library, resources). Use these questions in screening, technical interviews, or curriculum-design interviews. Grouped by topic; each question includes a short interviewer prompt where useful.

## Exercises (mapped to `curriculum/exercises.md`)

1. Describe an exercise you would create to teach a difficult concept from this curriculum. What are the learning objectives, steps, and expected outcomes?
2. How would you adapt an exercise for learners with limited time or lower baseline knowledge?
3. Give an example of an exercise that assesses practical application (not just recall). How do you grade or provide feedback on it?
4. Walk me through how you would scaffold an exercise from novice to advanced levels.
5. What accessibility considerations would you include when designing exercises (e.g., for visual/hearing impairments, or limited bandwidth)?
6. How would you measure whether an exercise improved learner competence (metrics, data collection)?
7. Describe a troubleshooting plan for an exercise that consistently underperforms in pilot testing.
8. Provide an example of an exercise you would convert into a group activity. What role structure and assessment would you use?

## Learning Resources (mapped to `curriculum/learning-resources.md`)

1. How do you choose high-quality learning resources for a module? List criteria and give an example.
2. Describe how you would curate a reading/list of resources at different depth levels (intro, intermediate, advanced).
3. When would you prefer video over written resources, and how do you evaluate their effectiveness?
4. Explain how you would keep resource lists current and what signals you'd use to retire an item.
5. How would you incorporate community-created resources while ensuring quality and safety?
6. Describe licensing or copyright checks you would perform before adding an external resource.

## Module Library (mapped to `curriculum/module-library.md`)

1. Describe the structure you would use for a reusable module (sections, metadata, prerequisites, outcomes).
2. How do you decide module length and granularity for a library targeted at working adults?
3. Give an approach to versioning and maintaining modules across cohorts.
4. How would you design a module to be interoperable with other modules (clear inputs/outputs)?
5. What automated checks or validations would you include when adding a module to the library?
6. Describe a strategy to map learner pathways (module recommendations) based on prior skills and goals.

## Resources (mapped to `curriculum/resources.md`)

1. How do you assess whether a resource is appropriate for career-focused vs general-education tracks?
2. Explain a simple taxonomy you would use to tag and search resources.
3. Describe how you'd integrate external partners' resources (e.g., hiring managers, industry content) while avoiding conflicts of interest.
4. What metadata fields are essential for each resource entry and why?
5. How would you guard against bias in resource selection (representation, cultural relevance)?
6. Describe strategies to surface high-value resources for learners who are overwhelmed by options.

---
Suggested interview usage: pick 6–8 questions total for a 30–45 minute interview (mix design, evaluation, and operational questions). For curriculum-design hires, emphasize Exercises and Module Library. For roles focused on content curation, emphasize Learning Resources and Resources.
